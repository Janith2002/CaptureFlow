# Contributing documentation and feedback

This repository currently publishes documentation and approved branding only. Application source is not authorized for public distribution. No open-source license or publisher identity is implied.

Open an issue for a documentation correction or reproducible problem. Documentation pull requests should identify the correction without posting private source, media, logs, credentials or projects. Use synthetic reproductions. No private vulnerability-reporting channel is approved; do not disclose sensitive exploit details publicly.

Keep implementation claims separate from human acceptance. The current formal baseline remains 20 PASS / 26 Not Run; do not upgrade it without complete evidence. See [privacy](PRIVACY.md).
