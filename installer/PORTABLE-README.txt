CaptureFlow 1.0.0 - PRIVATE Windows 11 x64 v1.0 validation build

Extract the entire ZIP into a new folder, then open CaptureFlow.exe. Keep all
DLLs, runtime files, assets, LICENSE and Licenses together. No installer or
separate .NET SDK/runtime installation is required. FFmpeg and FFprobe are
external: configure a compatible pair in Settings > External Tools.

This is installation-free, not a promise of portable settings: preferences,
library metadata, diagnostics and recovery use LocalAppData\CaptureFlow.

The executable is unsigned and remains subject to Windows application control.
Do not disable security protections if Windows blocks it. Report diagnostics.
Physical device tests remain deferred. Selecting camera modes can initialize
a device; keep those modes unselected for a device-free startup check.
Close the app normally before moving its folder.

Public release gates are incomplete. See PREVIEW-NOTICE.txt and license notices.

A version number is not acceptance evidence. This package is not an approved
stable release. Do not redistribute it before the release gates pass.
